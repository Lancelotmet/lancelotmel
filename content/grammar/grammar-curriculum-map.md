## Lancelot microcycle

Each capsule has a single mission and three short decisions. Across the five capsule functions for each skill the student moves through **discover → practice → correct → build → apply/master**, while feedback keeps the sequence **attempt → observe → compare → hypothesis → quick rule → transfer** available without turning the catalog into a linear LMS.

## Placement note

The initial placement is marked `strong-inference` in the structured curriculum where the source gives the grammatical topic but not a CEFR level. The PDF chapter/page trace remains attached to every skill and can be refined after the complete OCR audit.
